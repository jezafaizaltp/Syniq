Chapter names follow the rationalised NCERT books (2024–25 onwards), from memory: they have not been compared with a printed copy yet, and the topics inside each chapter were chosen by Claude. Hindi A covers thirteen Kshitij lessons (chapters 1–13, numbered in SYNiq's own order) and the three Kritika lessons (chapters 14–16). Hindi B is not written yet. Both language subjects were written from memory of the NCERT texts, not from the books, so names and details need checking, and the Hindi wording has not been read by a Hindi teacher.

## Who checked it

Claude wrote these chapters and checked them, because no subject teacher is available to the project yet. Every question is marked "Written and checked by Claude for SYNiq. Not yet reviewed by a school teacher." in the teacher's review screen. In detail:

- **Every answer that can be worked out by computer is**, on every test run: 902 of the 3,496 questions. Each one carries a `check`, a calculation done a different way from the answer (for example `expand((x + 4)*(x + 5))` for an expansion, or `(34 + 10)/2` for a sum-and-difference problem), and the test fails if the stored answer differs, or if a wrong option of a choice question also turns out to be right.
- The other 2,594 were checked by hand (most of them in the languages, Chemistry, Biology, Social Science and IT, where questions are about texts, facts and ideas): choice questions that no single calculation can check, such as "Add them", "Which is the smallest?" or, in science, "Which way does the ray bend?", and a few questions whose answer is read off a list or stated in the question, such as a mode.
- **The fit with the textbook is only partly checked.** The Physics, Chemistry, Biology, Social Science I, Social Science II and IT chapter names match the 2024 textbooks' contents pages; the Maths chapter names still come from study-guide websites (`../../content/class9-syllabus-draft.csv`). The topics inside each chapter were not taken from the books. A teacher with the 2024 SCERT books should compare topic order and wording when one is available.
- **The language chapters (English, Malayalam, Hindi) were written from the 2024 lesson texts themselves**, which the school supplied, so names, events and quotations come from the books. The lesson topics are the textbook's lessons; each unit adds one grammar or language topic from the unit's own exercises. The Malayalam and Hindi wording was written by Claude and has not been read by a native-speaking teacher yet.

## Format

```yaml
subject: math          # subject code
chapter: 1             # textbook chapter number
title: Pairs of Equations   # must match the chapter's title if it already exists

tips:                  # one sentence per mistake tag used below
  forgot_divide: "That is the total for more than one of the unknown. Divide ..."

concepts:
  - code: math9.pairs.sum_difference   # unique, never changed once students use it
    title: Two numbers from their sum and difference
    after: []                          # topics to learn first (codes)
    notes: |                           # what the textbook teaches; grounds the AI tutor
      ...
    explanations:                      # all four styles
      text: "..."
      visual: "..."
      step_by_step: "Step 1: ... Step 2: ..."
      real_world: "..."
    picture:                           # optional: drawn under the visual explanation (see Pictures)
      kind: flow
      steps: ["...", "..."]
      alt: "One sentence a screen reader says instead of the picture."
    items:
      - prompt: "The sum of two numbers is 34 and their difference is 10. What is the bigger number?"
        answer: "22"
        check: "(34 + 10)/2"           # required for typed answers
        difficulty: 1                  # 1 to 3; every topic needs 1s and 2s
        hints: ["...", "..."]
        solution: "Step 1: ... Step 2: ..."   # shown after a wrong answer, split at Step n:
        mistakes: {"44": forgot_divide}       # a likely wrong answer and its tag
      - prompt: "Expand (x + 5)²."
        options: ["x² + 10x + 25", "x² + 25", "x² + 5x + 25", "x² + 10x + 10"]   # 3 or 4
        answer: "x² + 10x + 25"
        check: "expand((x + 5)^2)"     # optional for choices; compares by value
        ...
```

Typed answers must be numbers (whole, decimal or a fraction like 3/4). Students' answers are accepted however the number is written: 22, 22.0 and 44/2 are all right. Anything else (an expression, a surd, words) is a choice question.

Mistake tags already translated into Malayalam in `backend/app/i18n.py` (`tip.<tag>`) can be used without a tip here. New tags need a tip in a pack (any pack: tips are shared), shown in English.

## Pictures

A topic can carry a `picture`: a small description that the app draws under its "Show me a picture" explanation. Nothing is downloaded, so it is free, works offline, stays sharp on any screen and follows dark mode and high contrast. `python -m app.content_packs --check` checks every picture the same way it checks answers (`backend/app/pictures.py`). Every picture needs an `alt` sentence for screen readers; `caption` is optional. Labels are at most 40 characters.

| kind | for | fields |
|---|---|---|
| `number_line` | numbers, jumps, distance | `from`, `to`, `step` (at most 40 ticks), `points: [{at, label}]`, `jumps: [{from, to, label}]` |
| `area_grid` | areas, identities, long multiplication | `cols` and `rows`: 1 to 4 `{size, label}`; `cells`: a label for every box, row by row |
| `bars` | bar charts; histograms with `touching: true` | 2 to 10 `{label, value}`, optional `unit` |
| `flow` | processes, timelines, worked steps | 2 to 8 `steps` |
| `compare` | two or three things side by side | 2 or 3 `columns: [{title, points}]`, 1 to 6 points each |
| `geometry` | shapes, angles, circles, graphs | `points: {A: [x, y]}` (0 to 10, or within `range` with `axes: true`), `segments: [[A, B, label]]`, `circles: [{centre, radius}]`, `angles: [{at, from, to, label}]`, `x_label`/`y_label` with axes |

In `geometry`, a point whose name starts with `_` is a helper: lines can use it but it isn't marked or named. Labels are placed on the outside of the shape automatically. Examples of every kind are in the CBSE Class 9 Maths packs.

## Changing a pack

```
cd backend
python -m app.content_packs --check   # checks everything, saves nothing
python -m pytest tests/test_content_packs.py
```

The pack is the source of truth for what it loaded. Editing a question's wording replaces it (the old wording is withdrawn, so students no longer see it). Explanations and questions that teachers add in the app are never touched. Changing a pack-loaded question in the app is overwritten the next time the server starts, so change the pack instead.
